# Signaltrust

## Definition

Calibrated confidence in an AI’s outputs based on repeated testing, transparency, and verification.

## In use

“Signaltrust increased only after the workflow consistently passed review.”

## Usage note

Trust should be scoped by task; reliability in one domain does not transfer automatically.
