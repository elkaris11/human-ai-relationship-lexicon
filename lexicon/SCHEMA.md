# Lexicon Entry Schema

Every accepted entry uses YAML front matter:

```yaml
term: Thinksync
status: accepted
category: interaction
part_of_speech: noun or verb
version_added: 1.0.0
```

Required sections:

1. Definition
2. In use
3. Usage note
4. Semantic Neighbors
5. History

## Semantic Neighbor relationships

Use these labels when the distinction is known:

- `synonym`
- `near-synonym`
- `broader`
- `narrower`
- `register-variant`
- `spelling-variant`
- `contrast`
- `process-neighbor`

Definition similarity is not an automatic rejection rule. A related word may serve another register, audience, scope, intensity, or community.
