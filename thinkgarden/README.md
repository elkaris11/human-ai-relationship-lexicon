# The Thinkgarden 🌱

The greenhouse for new lexical seedlings. Terms live here while the community tests whether they are clear, useful, memorable, distinct, and honest.

## Stages

- **Seed:** submitted, not yet checked
- **Germinating:** complete enough for discussion
- **Growing:** active testing and refinement
- **Ready for harvest:** eligible for final review
- **Harvested:** admitted to the Core Lexicon
- **Composted:** rejected or withdrawn, but preserved in the archive

The default incubation target is configured in `config/project.yml`. Maintainers can extend or shorten review when discussion is active, participation is low, manipulation is suspected, or the proposal changes substantially.
