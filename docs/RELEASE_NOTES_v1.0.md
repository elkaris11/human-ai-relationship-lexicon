# Community Edition v1.0 Release Notes

## Included

- 55 accepted Core Lexicon terms
- nine taxonomy categories
- five founding Thinkgarden seedlings
- Semantic Neighbor relationships
- contribution and governance framework
- automated validation and voting support
- generated Word, PDF, and combined Markdown booklets
- searchable GitHub Pages website

## Publishing model

Accepted Markdown term files are the source of truth. The website and booklet editions are generated from those files so public formats remain aligned with the repository.
