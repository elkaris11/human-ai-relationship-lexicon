# Voting and Harvest Review

Vote on the proposal issue using reactions:

- 👍 supports adding the term
- 👎 opposes adding the term

Other reactions are conversational and are not counted. GitHub's issue reaction counts provide the raw tally. The scheduled workflow records transparent snapshots.

## Default eligibility

Defaults live in `config/project.yml`:

- minimum incubation days
- minimum participating reaction votes
- minimum net score
- maximum opposition ratio

Meeting the numeric defaults makes a seedling **eligible for harvest review**, not automatically accepted. A Lexicographer confirms the proposal has a complete definition, usage example, boundaries, Semantic Neighbors, no unresolved duplicate problem, and no credible vote manipulation concern.

Substantive comments may outweigh a raw total. Maintainers must record the reason for harvest or compost decisions.
